# 会话成本卡

对话右侧一张平面卡片，回答两件事：**本会话花了多少**、**现在是峰还是谷、单价多少**。

无投影，用 `--dsw-alias-bg-layer-1` 的底色加 1px `--dsw-alias-border-l1` 描边分层，跟随宿主主题（深/浅色）切换。

## 显示内容

- **总额**：本会话估算花费，按每条请求的 usage 与它**结算时刻**所属档位折算。
- **逐桶账目**：输入（缓存未命中）/ 输入（缓存命中）/ 缓存写入 / 输出，各给 tokens 与**实际金额**；金额相加等于总额，不与单价表混算。
- **峰谷占比**：一条分段条 + 「其中高峰 ¥x · n 次 / 其中谷时 ¥y · m 次」。
- **峰谷单价**：命中 / 未命中 / 输出两列（谷时、高峰），当前档位列加重，另一列弱化。
- **倒计时**：距离下次峰谷切换的时间；另有一行「更新于 HH:MM」和估算口径说明。

## 价格口径

谷时单价（元 / 百万 tokens），高峰为 2 倍：

| 模型 | 输入（命中） | 输入（未命中） | 输出 |
|---|---|---|---|
| `deepseek-flash` | 0.02 | 1 | 4 |
| `deepseek-v4-pro` | 0.15 | 4.5 | 13.5 |

高峰 = 周一至周五 09:00–12:00、14:00–18:00（北京时间）；其余时间、周末、法定节假日全按谷时。`deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 按 Flash 计价；其它模型名按 Flash 计价并标注「未知模型」。

价目表是 `client.js` 里 `pure-helpers` 区块的常量（`FLASH` / `PRO` / `PRICES` / `ALIASES`），厂商调价时改这里并重载页面即可。

## 数据来源

客户端读本会话的 `SessionBinding.eventSource` 事件窗口，取 `assistant/message` 的 `data.usage`（缺失时回落到流里最后一个 `usage` chunk）与 `assistant/attempt`，按 `turn:step` 去重（重试以最后一次为准），模型取消息的 `source.model`，缺失时回落到最近的 `request/header`。窗口未加载完整时，副标题加「仅已加载」。

不新增服务、不写 session 事件、不调用模型。

## 已知限制

- 仅覆盖**已加载**的事件窗口；超长会话较早的历史未计入，卡片会标注。DSH 自带的 `tokenUsage` projection 有全量 token 合计，但没有峰谷拆分。
- 法定节假日日历未建模；档位取消息结算时间，跨越 09:00 / 12:00 / 14:00 / 18:00 边界的请求可能差一档。
- 缓存写入按未命中价计（与 `tokenUsage` 的桶语义一致），并在卡片上说明。
- 定位是固定值（`top: 92px; right: 18px`，`z-index: 600`），未读取宿主布局与层级标尺；右侧栏展开时卡片会浮在其上。
- 金额为估算值，不是账单。

## 预览
